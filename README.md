# LinkedIn — Plano de Correções | Erick André Garcia

Checklist interativo para correção e otimização do perfil do LinkedIn.

**Acesse:** https://erickandregarcia-ai.github.io/erickchecklist/

## Conteúdo

- Erros visíveis (prioridade alta)
- Inconsistências de dados
- Identidade visual
- Competências (15 skills-chave + sub-checklist)
- Formações e certificados pendentes
- Projetos a cadastrar
- Rotina de publicações (3 posts prontos com botão copiar)
- Métricas — baseline nov/2026

## Técnico

- `index.html` único (HTML + CSS + JS, sem dependências)
- Progresso salvo em `localStorage` do navegador
- Hospedado via GitHub Pages (branch `main`, raiz)
